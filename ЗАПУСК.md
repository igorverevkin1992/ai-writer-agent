# ЗАПУСК КОНВЕЙЕРА — пошаговая инструкция (Windows, PowerShell)

Для macOS команды те же, кроме отмеченных; вместо `.bat` — `Запустить_панель.command`.

## Шаг 0. Что должно быть установлено (один раз)

1. **Python 3.11 или новее** — https://www.python.org/downloads/ . При установке
   поставьте галочку **«Add python.exe to PATH»**.
2. **Git** — https://git-scm.com/download/win (все настройки по умолчанию).

Проверка в PowerShell (обе команды должны напечатать версию):

```powershell
py --version
git --version
```

## Шаг 1. Получить актуальный код

```powershell
cd <папка-репозитория>          # например: cd "D:\проекты\ai-writer-agent"
git pull                        # рабочая ветка — та, в которой ведётся разработка (по умолчанию main)
```

Если папки ещё нет:

```powershell
git clone https://github.com/igorverevkin1992/ai-writer-agent
cd ai-writer-agent
```

## Шаг 2. Ключи API (один раз)

В корне папки создайте файл `.env` (без имени, только расширение):

```powershell
notepad .env
```

Содержимое — две строки, без кавычек и пробелов вокруг `=`:

```
GEMINI_API_KEY=ваш_ключ_Gemini
ANTHROPIC_API_KEY=ваш_ключ_Anthropic
```

Сохраните. Файл в `.gitignore`, в репозиторий не попадёт. Без ключей всё
работает в ручном режиме (промпты сохраняются в файлы, ответы моделей
вставляются в панели).

## Шаг 3. Запуск панели

### Вариант А — двойной клик (рекомендуется)

Откройте папку в Проводнике и дважды щёлкните `Запустить_панель.bat`.

- Первый запуск: скрипт создаёт окружение `.venv` и ставит конвейер (1–3 мин).
- Затем открывается браузер с панелью: http://127.0.0.1:8765 .
- Чёрное окно — это сервер. Закрыть окно = остановить панель.

### Вариант Б — из PowerShell

```powershell
cd <папка-репозитория>
py -m venv .venv                       # один раз
.\.venv\Scripts\Activate.ps1           # каждый новый сеанс PowerShell
python -m pip install -e ".[llm,dev]"  # один раз (и после git pull)
chcp 65001                             # русские буквы в терминале
ugar doctor                            # диагностика: ключи, SDK, git, выгрузки
ugar panel                             # панель в браузере
```

Если PowerShell отказывается выполнять `Activate.ps1`, один раз:

```powershell
Set-ExecutionPolicy -Scope CurrentUser RemoteSigned
```

## Шаг 4. Первый сеанс в панели

1. **Экспорт канона** (кнопка слева) — библиотека `УГАР_Библиотека/` → `exports/`.
   Делается автоматически перед каждым шагом, кнопка нужна после ручной правки канона.
2. **Круги истории** (кнопка слева) → **«Построить все круги»**: круг тома, четыре
   акта, 46 глав — 51 вызов модели Anthropic. Дождитесь окончания (лог справа).
3. Просмотрите круги (клик по карточке раскрывает 8 шагов и «слабое место»).
   Не нравится — **«Пересчитать всё»** или пересчёт одного уровня (Книга / Акты / Главы).
4. **«Внести в канон»** — круги записываются в `УГАР_Библиотека/21_Круги_истории_Том1.md`
   и коммитятся. С этого момента окно каждой главы содержит секцию «Драматургия».
5. Границы актов при необходимости правятся в таблице «Акты тома» того же документа,
   затем **Экспорт канона**.

## Шаг 5. Такт главы в панели

1. В очереди слева выберите главу (например, «Глава 1 · не начата»).
2. **«Продолжить такт ▶»** — конвейер выполняет машинные шаги подряд:
   сборка окна → Писатель (Gemini) → проверки Э1 → проверки Э2 (Claude) → пакет приёмки,
   и останавливается на паузе автора.
3. **Приёмка** (вкладка «Чтение с флагами»): текст с подсветкой флагов;
   вкладка «Правки» — впишите правки в формате БЫЛО/СТАЛО; по каждой самоволке
   нажмите «Вычеркнуть» или «Канонизировать →».
4. **«Продолжить такт ▶»** — Писатель вносит правки, дифф-контроль сверяет
   внесённое.
5. Если «дифф-контроль: чисто» — **«Принять главу»**. Затем **«Пакет в канон»**:
   просмотрите/поправьте пакет записей и **«Применить пакет + коммит»** — текст главы
   и записи реестров уходят в библиотеку и коммитятся.
6. Глава становится «зафиксировано». Дальше следующая глава.

Вкладка «Окно / ручной режим» позволяет пройти всё без ключей: скопировать промпт,
вставить ответ модели.

## Шаг 6. То же самое из терминала (по шагам)

```powershell
ugar status            # все главы и что делать дальше
ugar run 1             # весь такт главы 1 с паузами на шагах автора
# либо по шагам:
ugar compile 1         # окно контекста → chapters/001/window.md
ugar write 1           # Писатель → draft_1.md   (--manual без ключа)
ugar verify1 1         # Э1 (скрипты)
ugar verify2 1         # Э2 (Claude)            (--manual без ключа)
ugar review 1          # review.md / review.html, edits.md, resolutions.json
ugar resolve 1         # решения по самоволкам
ugar apply-edits 1     # правки Писателем
ugar diff-check 1      # дифф-контроль
ugar accept 1          # приёмка
ugar canonize 1        # пакет на подпись
ugar canonize 1 --apply
```

Круги истории из терминала:

```powershell
ugar circles всё       # или: книга | акты | главы [--глава N]; --заново пересчёт
ugar circles --в-канон # внести черновики в документ 2.1 и закоммитить
```

Служебное:

```powershell
ugar doctor                       # диагностика
ugar canon-commit -m "текст"      # закоммитить ручную правку библиотеки
ugar backup --push                # бэкап библиотеки во все remotes
ugar rollback 1                   # откат главы на шаг назад
ugar dashboard --открыть          # дашборд
ugar find "Штерн"                 # поиск по канону
python -m pytest tests/ -q        # тесты (215)
```

## Шаг 7. Обновление кода

```powershell
cd <папка-репозитория>
git pull
.\.venv\Scripts\python.exe -m pip install -e ".[llm,dev]"
```

## Если что-то не так

| Симптом | Что делать |
|---|---|
| `ugar` не распознано | Активируйте окружение `.\.venv\Scripts\Activate.ps1` или вызывайте `.\.venv\Scripts\python.exe -m ugar panel` |
| Порт занят | `ugar panel --port 8766` |
| Кракозябры в терминале | `chcp 65001` |
| «Не найден GEMINI_API_KEY / ANTHROPIC_API_KEY» | Проверьте `.env` в корне папки; либо работайте в ручном режиме |
| Панель не открылась сама | Откройте в браузере http://127.0.0.1:8765 |
| «в библиотеке незакоммиченные изменения» | `ugar canon-commit -m "правка канона"` и повторите |
| Сомнения в установке | `ugar doctor` |
