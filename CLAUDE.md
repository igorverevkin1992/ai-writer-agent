# КОНВЕЙЕР УГАР — карта проекта

Локальный конвейер производства книжной серии по ТЗ «КОНВЕЙЕР УГАР» v1.0
(текст ТЗ — в истории репозитория/у автора). Главный принцип §1.3: никакого
облака; наружу выходят только вызовы API моделей (Gemini — Писатель,
Anthropic — Верификатор-2/Канонист). Все канонические решения — за автором.

## Команды разработки

```bash
pip install -e ".[llm,dev]"      # установка (llm — SDK моделей, опционально)
python -m pytest tests/ -q       # тесты (все должны быть зелёными)
cd panel && npm ci && npm run build   # пересборка React-панели → ugar/data/панель/
```

Прогон вживую: `mkdir демо && cd демо && ugar init --демо && ugar panel`.

## Архитектура (кратко)

- `ugar/cli.py` — все команды (`ugar …`); каждый шаг такта — отдельная команда
  (FR-O2), у долгих есть `--manual` для ручного режима (NFR-3).
- `ugar/fsm.py` — конечный автомат главы (§5.4), состояние в `chapters/N/status.yaml`.
- `ugar/guard.py` — единственная точка записи файлов; путь в `УГАР_Библиотека/`
  открыт только внутри `canon_write_session()` (FR-K3) — не обходить.
- `ugar/exporter.py` — MD-канон → `exports/*.json`; разбирает ВСЁ до записи
  (атомарность); форматы MD — по `ugar/data/демо/УГАР_Библиотека/ИНСТРУМЕНТ_Соглашения_разметки.md` (Д-1).
- `ugar/verifier1.py` — проверки Э1; пороги ТОЛЬКО из norms.json (критерий 6),
  констант в коде быть не должно.
- `ugar/verifier2.py`, `ugar/canonist.py` — LLM-роли; JSON из ответов — через
  `ugar/llmjson.py`; деградация без API обязана сохраняться.
- `ugar/server.py` — локальный сервер панели (только 127.0.0.1); вызывает
  функции cli, POST защищён заголовком `X-Ugar-Panel`; одна фоновая задача
  за раз (redirect_stdout глобален — см. `ensure_idle`).
- `panel/` — исходники React-панели; сборка КОММИТИТСЯ в `ugar/data/панель/`
  (авторам не нужен Node). После правок фронтенда обязательно пересобрать.

## Ловушки

- Функции команд typer нельзя вызывать напрямую с дефолтами: `typer.OptionInfo`
  истинен. Всегда передавать явные значения (`cmd_write(n, manual=False)`).
- `typer.Exit`/`Abort` наследуют `RuntimeError` — учитывать в except.
- Тесты используют демо-библиотеку из `ugar/data/демо/` (фикстура `ws`).
- Кириллические имена файлов и русские сообщения — намеренно (NFR-2, NFR-8).
- Дашборд и review.html обязаны работать без сети — никаких CDN.

## Правила изменений

- Новые пороги/правила прозы добавлять в канон (02 §5) и exporter, не в код.
- Любой новый путь записи в библиотеку — только через canonist + подпись.
- Русский язык интерфейса и сообщений; после изменений — полный pytest,
  фронтенд — пересборка и, по возможности, живой прогон `ugar panel`.
