# История изменений — КОНВЕЙЕР УГАР

Правило версий и тегов: код конвейера получает тег `v1.N` (N растёт на единицу на каждый релиз;
`v1.0` — реализация ТЗ v1.0, дальше — этапы аудитов). Тег ставит автор вручную после того, как
`python -m pytest tests/ -q` зелёный и панель пересобрана: одним коммитом обновляются `version`
в `pyproject.toml` и `ugar/__init__.py`, раздел «Не выпущено» ниже переименовывается в `v1.N —
дата`, затем `git tag v1.N && git push origin v1.N`. `ugar --version` печатает версию
установленного пакета. Теги канона — отдельная система в репозитории библиотеки:
`глава-N` при каждой приёмке (`canonize --apply`), `глава-N-2` при повторной приёмке после отката.

## Не выпущено (будущий v1.6) — 18.09.2026, второй аудит, этап 5 (п. 28, 29, 31)

- Сохранность: `ugar library-split [--показать] [--в] [--с-историей]` — библиотека канона как
  отдельный git-репозиторий рядом с рабочей областью (`library_dir` в config.yaml, запись в
  `.gitignore`, пересчёт SHA приёмок при переносе истории); `doctor` различает три раскладки
  («корень собственного репозитория», «внутри репозитория кода», «не под git»).
- `ugar backup --добавить-remote <имя> <url|папка>` — второе место хранения; папка на внешнем
  диске создаётся как bare-репозиторий (вариант без облака, §1.3 ТЗ).
- `ugar backup --архив [папка]` — zip рабочей области (`chapters/ logs/ круги_истории/ snapshots/
  regression/ config.yaml`) с ротацией (`backup_keep`); автоматически после каждой приёмки при
  `backup_dir` в config.yaml; возраст архива — в `doctor` и `backup`.
- Тег `глава-N` на коммит приёмки (`gitops.tag_chapter`), повторная приёмка — `глава-N-2`;
  `rollback` теги не трогает.
- `doctor` сверяет пины моделей из config.yaml с API (только чтение метаданных, короткий
  таймаут): «есть в API» / «не найдена — `ugar retest`» / «не проверено».
- `writer.params.thinking_config.thinking_level` в config.yaml (форма google-genai, Д-6);
  адаптер передаёт `params` как есть.
- Версии: `pyproject.toml` — `google-genai<3`, `anthropic<2`, `ruff` в dev; `requirements.lock`;
  `ugar --version`; CI — macOS в матрице, `ruff` во всех python-джобах, джоба по lock-файлу.
- ЭКОНОМИКА.md §9: `lint --llm`, `verify2 --вкус/--повторно`, `write --варианты`.
