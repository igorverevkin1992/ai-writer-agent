## МУР (Московский уголовный розыск)

- Создан в 1918-м в системе розыска НКВД РСФСР ✓
- **В 1926-м — самостоятельная структура Исполкома Моссовета** (не в составе милиции!) ✓
- **Адрес: Большой Гнездниковский переулок** ✓ — все интерьеры МУРа томов 1–6 здесь
- **1931: МУР входит в состав московской милиции и переезжает на Петровку, 38** ✓ — тома 7+ физически в другом здании; смена дома = смена эпохи, использовать как деталь т.7
- Персональных званий нет до 1936 года ✓ — обращения по должности; звания в цикле II (с т.8) — сверить введение спецзваний милиции ⚠
- Должностная лестница 1920-х: агент (разряды) → субинспектор → помощник инспектора → инспектор → начальник отделения → начальник МУРа ⚠ (уточнить точную номенклатуру; Степан — «помощник инспектора» — в рамке эпохи ✓)
- Начальник МУРа в 1926-м (реальное лицо) — не установлен без архивной сверки ⚠; в каноне пост занимает вымышленный Бугаев 🔧 (реальные начальники в тексте не называются — Р-запись при первом упоминании)
- Методы: картотеки, дактилоскопия, агентура в уголовной среде, «летучие» группы ✓ (детализация — при сценах)
- Судебно-медицинская экспертиза: морги и эксперты формально в системе здравоохранения (Мосздравотдел), прикомандированы к следствию ⚠ точная схема; канон: Штерн — эксперт, постоянно работающий на МУР 🔧 (закреплено легендой сети)

## ОГПУ при СНК СССР

- Лубянка, 2; внутренняя тюрьма ✓ (убийство посредника — гл. 34 т.1 — здесь)
- Председатель: Дзержинский → с 30.07.1926 Менжинский ✓; зампред Ягода — фактическая повседневная власть при болезненном Менжинском ✓
- Ключевые управления для серии: **КРО** (контрразведка; ведёт «Трест»; Артузов) ✓ · **ЭКУ** (экономическое управление: валюта, фальшивомонетничество, спецы — обе линии тома 1) ✓ · СО (секретный: партии, интеллигенция) ✓ · ИНО (внешняя разведка) ✓
- Милиция и угрозыск — республиканское подчинение (НКВД РСФСР/Моссовет), ОГПУ — союзное: межведомственная граница, на которой стоит весь конфликт МУР/Лубянка ✓
- **Позиция Заварзина** 🔧: каноническая условность «заместитель председателя московского ОГПУ»; в прозе должность называется обтекаемо («с Лубянки», «из коллегии», «зампред») без привязки к реальной номенклатуре ПП ОГПУ по Московской губернии ⚠ — окончательная формула при поглавнике т.1
- Куратор Степана 🔧: оперуполномоченный линии спецпроверки кадров; персона — ⚠ досье второго круга при поглавнике
- Линия изменений для цикла II: ОГПУ → НКВД СССР (07.1934, ГУГБ в составе) ✓ → НКГБ/НКВД разделения 1941/1943, СМЕРШ (1943) ✓ — терминология каждой эпохи в соответствующих томах; сверочная таблица аббревиатур по годам — дополнить при арках томов 7–10 ⚠

## «Континенталь» (вымышленный, канон серии)

Частный консорциум национализированных в 1917-м европейских капиталов. Не воюет со странами — инвестирует в исходы. Три стратегии: «Знать» (1918–26) → «Вернуть или обесценить» (1926–29) → «Хеджировать» (с 1929; ликвидация филиала, «мюнхенская конюшня», третье переложение 1944). Структура присутствия: бенефициары (Лондон/Лозанна, недосягаемы) → кураторы → казначеи → внутренние агенты → соисполнители → исполнители (предметная иерархия — 1.5). Разведки — контрактные подрядчики, не хозяева. Экономика сети и «архивная» глубина — дорабатываются при арках томов 2–5 ⚠.
